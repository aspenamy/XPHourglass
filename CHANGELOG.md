# Changelog

## 0.1.0

First build for World of Warcraft: Forever.

- Percent, rested XP, XP per hour, time to level and kills to level written onto Blizzard's XP bar.
- Quest XP waiting to be turned in is shaded gold on the bar, in any color you pick.
- Hover the bar for the full stats, including time on the level and the session.
- The clock pauses while you're AFK, and the session survives a /reload.
- A chat line on level up with how long the level took.
- Put each stat on the left end of the bar, the center or the right end, or hide it.
- Set the text's font, size and outline, how far in from the ends it sits, and nudge it up or down.
- Settings page under Options > AddOns > Hourglass, and `/xph` commands.
